# DE-INES Physiotherapy

Website for **DE-INES Physiotherapy and Sports Consults** in Benin City, Edo State, Nigeria.

Restoring mobility and enhancing well-being through expert physiotherapy consultation.

## Features

- Home, Services, Training, Gallery, and Contact pages
- WhatsApp booking buttons
- Google Maps location on the Contact section
- Responsive design with Tailwind CSS
- Animations with Framer Motion

## Tech Stack

- React 19
- TypeScript
- Vite
- Tailwind CSS v4
- React Router
- Framer Motion
- Lucide React

## Local Development

### Install dependencies

```bash
pnpm install
```
